# Smart Clinic Database System

> **SEU Project – CS350 Database Course**

## Project Overview
This is a university project developed for the Saudi Electronic University (SEU) as part of the CS350 Database course.

The project implements a Smart Clinic Database System using MySQL to manage:
- Patients
- Doctors
- Appointments
- Medical Reports
- Medicines
- Prescriptions
- Payments

## Features
- ER/EER Database Design
- Relational Schema
- MySQL Implementation
- SQL Queries (SELECT, JOIN, Nested Queries)
- GROUP BY & Aggregate Functions
- VIEW and TRIGGER
